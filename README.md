# GHOSI Music Player — Android 7+ APK project

This is a minimal Android WebView wrapper for the **published** GHOSI web player at https://ghosi.floot.app. It is **not** an offline/native port of the Floot source and requires internet access to load the player. The published Floot site must be updated separately if it lags behind the editor preview.

Android 7+ (API 24), debug APK generated by GitHub Actions. WebView file selection is enabled, but local MP3 handling and playback on Xperia XZ Premium must be tested.

To build: upload this folder's contents to a GitHub repository (preserving folder paths), then go to Actions > Build GHOSI Android APK > Run workflow. Download the `GHOSI-Android-APK` artifact after a successful build, unzip it, and install `app-debug.apk` on your own Android phone.

The workflow builds a debug-signed APK for private testing; it is not a production release.
